# `src/components/` — componentes de interface

**Território: PH.**

Componentes React reutilizáveis (botões, cards de jogador, tabela de
classificação etc.), estilizados com Tailwind CSS.

Componentes não devem acessar o banco nem código de `src/server/`. Os dados
chegam por props, tipados com os tipos de `src/contracts/`.
